# 项目启动指南

## 一、环境要求

| 依赖 | 最低版本 | 说明 |
|------|----------|------|
| Node.js | 18+ | JavaScript 运行时 |
| npm | 9+ | 包管理器（随 Node.js 一同安装） |

> **检查版本：**
> ```bash
> node -v   # 应输出 v18.x.x 或更高
> npm -v    # 应输出 9.x.x 或更高
> ```

---

## 二、快速启动

```bash
# 1. 进入项目根目录
cd D:\Desktop\vue前端文件\admin-frontend

# 2. 安装项目依赖（首次启动或依赖变更后需要执行）
npm install

# 3. 启动开发服务器
npm run dev
```

启动成功后，浏览器打开 **http://localhost:5173** 即可访问。

## 五、代理配置说明

开发环境下的请求代理配置位于 `vite.config.js`：

```js
server: {
  port: 5173,          // 前端开发服务器端口
  proxy: {
    "/api": {          // 匹配所有以 /api 开头的请求
      target: "http://localhost:8080",  // 转发到后端地址
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/api/, "")  // 去掉 /api 前缀
    }
  }
}
```

**请求流程示意：**

```
前端发起请求:   GET http://localhost:5173/api/system/user/list
                      ↓  代理转发（去掉 /api）
后端接收请求:   GET http://localhost:8080/system/user/list
```

## 八、常见问题

### Q1：`npm install` 报错或很慢？

```bash
# 使用淘宝镜像加速
npm config set registry https://registry.npmmirror.com

# 然后再安装
npm install
```

### Q2：启动后页面白屏 / 接口 404？

确保后端服务已启动并监听在 **8080** 端口。如果后端端口不同，请修改 `vite.config.js` 中 `proxy.target` 的值。

### Q3：登录时报接口错误？

确认后端 `/api/auth/login` 接口可用。开发环境下，实际请求会转发到 `http://localhost:8080/auth/login`。

### Q4：端口 5173 被占用？

Vite 会自动尝试递增端口号（5174、5175...），观察控制台输出的最终端口即可。也可以修改 `vite.config.js` 中的 `server.port`。

### Q5：生产部署如何配置？

```bash
# 构建
npm run build

# 产物在 dist/ 目录，直接部署到 Nginx 等静态服务器即可
```

需要在生产环境配置 Nginx 反向代理，将 `/api` 请求转发到后端服务，参考配置：

```nginx
location /api/ {
    proxy_pass http://backend:8080/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```
